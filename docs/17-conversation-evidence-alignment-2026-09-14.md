# Conversation evidence alignment — 14 September 2026

The conversation review found that some replies treated a saved booking or public-app instructions as proof of email delivery, ticket display or admission. It also found requests to widen a swap search without permission and reserve a newly calculated wallet/card split before its amounts were accepted.

The system prompt, tool guidance and booking/payment/change Procedures now use the actual returned evidence. A pause waits for substantive customer input; a request for a complete recommendation gets its read-only proposal before acceptance. New balance splits require disclosure followed by acceptance. Rejected booking matches remain handover context, not invented transaction references. Public website/app instructions are scoped to those channels. Reviewed knowledge files are preserved by the knowledge generator.

The age tool now combines GOLD/THEATRE screen restrictions with the film classification: under five is refused; ages five through eighteen require a parent or guardian, subject to the film rating. An unknown film rating remains unconfirmed. This follows the [VOX UAE FAQ](https://uae.voxcinemas.com/faq) and [THEATRE entry policy](https://uae.voxcinemas.com/ways-to-watch/theatre). Empty swap results identify the verified search scope and request permission before widening it; successful preview behavior is unchanged.

Local validation: 743 tests across 70 files passed against the isolated test database; package compilation and project type checks passed. Lint passed with 231 existing warnings. The generated OpenAPI description matches the age tool. Independent source and knowledge-bundle reviews found no blockers.

This source change does not certify conversational acceptance or change the live ElevenLabs model. The V10 candidate uses separately created knowledge documents, tool definitions and native test definitions. Its full English/Arabic transcript review and verified promotion are separate release gates. Gemini 3.7 accepts Low reasoning; model defaults remain Gemini 3.6 Minimal until a tested configuration is chosen. Voice, privacy, session timers and customer demo records are preserved.
