Any page, with Voxi on it

This page has its own fonts and styles. The Voxi launcher at the bottom-right comes from one script tag and renders in its own Shadow DOM, so neither side's CSS leaks into the other.

<script src="https://voxi-demo.up.railway.app/embed/voxi.js" charset="utf-8" defer></script>

Optional: data-lang="ar" to start in Arabic, data-api="https://…/api" to point at another concierge API, data-open="true" to start expanded.

From your own page you can call Voxi.open(), Voxi.login(), Voxi.logout() and Voxi.unmount().
